# Changelog

## 1.2.1 - 2026-10-13

### Fixed

- Scale and align collapsible bullet chevrons with Presentation 2 text.
- Keep native horizontal block views visible and within Presentation 2 slides, including when collapsible bullets are enabled.
- Remove blank separator space from horizontal Presentation 2 blocks.

## 1.2.0 - 2026-09-13

### Fixed

- Keep presentation text, links, tables, native headings, code, and embeds readable when graph themes such as Roam Studio Craft are enabled.

## 1.0.1 - 2026-08-16

### Added

- Added an experimental native Roam renderer through `{{presentation2}}` and `{{slides2}}`, supporting native Roam content and extension-owned renderers while preserving Reveal presentation features and the existing `{{presentation}}` and `{{slides}}` renderer.
